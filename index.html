하루 참여하지 않으면 다음날로 밀리므로 가급적 3일 모두 참여하여 진행이 늦어지지 않도록 부탁드립니다.

★★ 참여방법
✓ 화면 좌측 퀘스트 목록에서 '불멸자의 시험' 선택
✓ 보이지 않을 경우 좌측 문서 아이콘(퀘스트 목록)을 눌러 확인
★★ 필수 확인
✓ 퀘스트 완료 후 반드시 [보상받기] 버튼까지 눌러야 최종 완료됩니다.
✓ 보이지 않을 경우 좌측 문서 아이콘(퀘스트 목록)을 눌러 확인

⚠️ 미완료 시 불이익
  • ❌ 코르부스 탐험 참여 불가
  • ❌ 카이온의 시련 참여 불가
  • ❌ 추방의례 / 칼날철야 참여 불가

✓ 불멸단의 시험: 첫 주 3일간 진행
